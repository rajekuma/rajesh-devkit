# Workflow

- Work milestone by milestone from PROGRESS.md; start the loop with
  `devkit continue`, stop it with `devkit pause`.
- A spec is Draft until the owner marks it Approved; nothing is built from a
  Draft.
- One branch per milestone or phase: <naming, e.g. feat/phase-2-billing>.
- Commits and pull requests are the owner's call <unless the deliver stage is
  enabled>.
- Deferred work goes in PROGRESS.md's "Tracked follow-ups", never only in a
  spec.
